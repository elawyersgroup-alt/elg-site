# elg-site — исходники сайта argument-law.ru

Публичный репозиторий с исходниками сайта ELAWYERS GROUP (ИП Еланский И. Ю.), хостинг Hostland. Здесь лежит ровно то, что отдаётся браузеру: HTML, `sitemap.xml`, `robots.txt`, иконки, OG-картинка, один PDF, образцы для страниц. Ничего серверного (конфиги хостинга, `.htaccess`, пароли, ключи) в репозитории нет и быть не должно.

## Правило

**Источник истины — этот репозиторий.** На Hostland уходит только то, что закоммичено. Правок на сервере мимо git больше нет: если файл поправлен в файловом менеджере хостинга, он считается потерянным до тех пор, пока не перенесён сюда. Порядок: правка → коммит → выгрузка на Hostland тем же файлом.

## Как получена первая копия (17.09.2026)

Сайт снят по HTTPS с `https://argument-law.ru/` по `sitemap.xml` (51 адрес) с обходом всех локальных ссылок и `url()` в стилях; серверные файлы этим способом не видны и не снимались. Получено: 51 HTML, `sitemap.xml`, `robots.txt`, `favicon.ico`, `apple-touch-icon.png`, `og-image.jpg`, `files/chek-list-uvedomlenie-15-minut.pdf`. В статусе фирмы от 30.08 упоминаются 54 HTML: три файла, если они есть на сервере, ни с одной страницы не слинкованы и в sitemap не входят — их надо забрать из панели Hostland отдельно (см. «Что не снято»).

Каталогов `css/`, `js/`, `img/` (кроме `img/samples/`) на сайте нет: стили и скрипты у каждой страницы встроены в неё.

## Как устроены стили, меню и подвал

**Общего CSS-файла нет.** Каждая страница несёт свои стили в трёх (у 8 страниц — четырёх) блоках `<style>` внутри `<head>`:

| Блок | Что это | Одинаков дословно |
| --- | --- | --- |
| `<style>` № 1, ~10 КБ | дизайн-система: токены `:root` (`--paper`, `--ink`, `--stamp`…), сетка `.wrap`, шапка `header`/`.nav`/`.nav-links`, кнопки `.btn`, подвал `footer`, адаптив | 48 из 51; отличаются `index.html`, `ekspress-razbor.html`, `razbor-priostanovki.html` (дополнительные правила) |
| `<style>` № 2, ~2,8 КБ | стили сервисной страницы: `.svc-hero`, карточки, таблицы, FAQ | 50 из 51 (на главной свой) |
| `<style>` № 3, 180 байт | правило меню для ширины от 961 px | 49 из 51 |
| `<style>` № 4 | только у 8 страниц с блоком экспресс-разбора / чек-листа | — |

Шрифты — IBM Plex Serif / Sans / Mono с Google Fonts (`<link>` в каждой странице).

**Меню (`<header>` с `<nav class="wrap nav">`)** вставлено в каждый файл дословно, не подключается. На 50 страницах — байт в байт одно и то же; на `index.html` тот же состав, но ссылки без ведущего `/` (якоря `#problems` вместо `/#problems`) и обёртка `<div class="wrap nav">` вместо `<nav>`. Пункты: «С чем работаем», «Как это устроено», «Кадастр», «Порядок», «Партнёрам», «Инженерам», кнопка «Заказать экспертизу». Логотип — PNG в base64 внутри `<header>` (около 11 КБ в каждом файле).

**Подвал (`<footer>`)** тоже вставлен дословно. На 47 страницах одинаков (строка «© 2026 · ELAWYERS GROUP · Реквизиты · Политика конфиденциальности» и строка ссылок «О компании · Контакты · Telegram · Москва и Московская область»); отличаются четыре: `index.html` (добавлен пункт «Кадастровым инженерам»), `kontakty.html`, `o-kompanii.html`, `rekvizity.html` (укороченная вторая строка).

**Другие повторяющиеся дословно фрагменты** (правятся сразу во всех файлах):

- `<link>` на Google Fonts, `favicon`, `apple-touch-icon`, `og:image` — на всех 51;
- счётчик Яндекс.Метрики `ym(110859643, …)` — на всех 51 (у 7 страниц вызов повторён 2–4 раза);
- JSON-LD `LegalService` — на 11 страницах;
- блок согласия `#ld-consent` со sticky-панелью экспресс-разбора — на 7 страницах;
- контактный блок с телефоном +7 (985) 280-73-76 — на 49.

**Правка общих фрагментов (меню, подвал, шрифты, метрика) делается скриптом по всем файлам, не руками.** Готовый скрипт для ссылок на новую страницу — `tools/add_nav_links.py` (по умолчанию dry-run, запись только с `--write`; окончания строк CRLF сохраняет). Каталог `tools/` на Hostland не выгружается. Заготовка для других замен:

```python
import glob
OLD = '…точный старый фрагмент…'; NEW = '…новый фрагмент…'
for f in glob.glob('*.html'):
    t = open(f, encoding='utf-8').read()
    if OLD in t: open(f, 'w', encoding='utf-8').write(t.replace(OLD, NEW)); print('исправлен', f)
    else: print('НЕТ фрагмента —', f)   # index.html и три страницы с другим подвалом правятся отдельно
```

После массовой правки `git diff --stat` должен показать ровно те файлы, что ожидались.

## Что не снято и почему

- Серверные файлы (`.htaccess`, конфиги, логи) — не отдаются браузеру, в репозиторий не входят по правилу выше.
- Три HTML из «54» статуса 30.08, если они существуют: не слинкованы и не в sitemap; снимаются из панели Hostland (elFinder) Игорем или после выдачи доступа к FTP.
- Оферта экспресс-разбора живёт внутри `ekspress-razbor.html` (якорь `#oferta`), отдельного файла нет.
